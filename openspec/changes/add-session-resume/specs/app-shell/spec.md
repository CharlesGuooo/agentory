## ADDED Requirements

### Requirement: 历史会话视图与侧栏分离

系统 SHALL 把已索引的历史会话放在一个**独立视图**中，SHALL NOT 把它们直接列进侧栏。

侧栏是工作集（几十条量级，D-5）；历史是档案库（本机实测 437 条）。
两者合成一个列表是这个界面最容易死的地方。
另外 D-8 规定默认从 0 开始 —— 历史视图必须由用户显式打开。

#### Scenario: 侧栏内容不受索引影响

- **WHEN** 索引扫出数百条历史会话
- **THEN** 侧栏仍然只显示应用当前管理的会话
- **AND** 历史条目不出现在侧栏

#### Scenario: 显式打开

- **WHEN** 用户点击侧栏的「历史会话」入口
- **THEN** 历史视图打开，显示已索引的会话数

### Requirement: 历史条目要显示足以辨认的信息

每条历史会话 SHALL 显示 agent、工作目录、最后活动时间；有原生标题时 SHALL 一并显示。

#### Scenario: 工作目录已消失的条目

- **WHEN** 某条会话的工作目录已不存在
- **THEN** 该条目被明确标记，且其恢复入口不可用
- **AND** 条目本身仍然列出 —— 不因为目录没了就把用户的历史藏起来

#### Scenario: 时间不精确的条目

- **WHEN** 某条会话的最后活动时间是退回 mtime 得来的
- **THEN** 该时间被标注为不确定，而不是与精确时间混同呈现

### Requirement: 从历史恢复一条会话

系统 SHALL 允许从历史视图直接恢复一条会话，在新标签页中打开。

#### Scenario: 恢复成功

- **WHEN** 用户点击一条工作目录仍存在的历史会话
- **THEN** 新建一个标签页，在该会话的真实工作目录下执行其恢复命令
- **AND** 历史视图关闭，焦点移入新终端

#### Scenario: 恢复失败要说清楚

- **WHEN** 恢复命令启动失败（如 agent 已被卸载）
- **THEN** 终端中显示指明命令名与失败原因的错误
- **AND** 不留下空白的标签页
