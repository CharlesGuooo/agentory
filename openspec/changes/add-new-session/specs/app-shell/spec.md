## ADDED Requirements

### Requirement: 新建会话选择器

点击「新建会话」SHALL 打开一个选择器，让用户选定 agent 与工作目录后在新标签页中起会话。
界面上 SHALL NOT 存在任何点了没有反应的控件。

原规格完全没有定义这个按钮的行为，导致它作为一个假承诺在界面上存在了两个变更之久。

#### Scenario: 点击有反应

- **WHEN** 用户点击「新建会话」
- **THEN** 选择器打开
- **AND** 焦点移入选择器

#### Scenario: 选定后起会话

- **WHEN** 用户选了一个 agent 和一个存在的工作目录并确认
- **THEN** 新建一个标签页，在该目录下启动该 agent
- **AND** 选择器关闭，焦点移入新终端

#### Scenario: 未选全时不能确认

- **WHEN** agent 或工作目录尚未选定
- **THEN** 确认按钮不可用
- **AND** 不出现"点了没反应"的状态

#### Scenario: 启动失败要说清楚

- **WHEN** 启动失败
- **THEN** 选择器内显示指明 agent 与原因的错误，且保持打开
- **AND** 不留下空白标签页

### Requirement: 目录既可从候选选，也可浏览，也可手输

系统 SHALL 同时提供三种给出工作目录的方式：从索引来的候选中选、
通过系统原生目录对话框浏览、直接手输路径。

#### Scenario: 原生对话框

- **WHEN** 用户点击浏览
- **THEN** 打开操作系统自己的目录选择对话框
- **AND** 选定后填入输入框

#### Scenario: 手输的路径同样要校验

- **WHEN** 用户手输了一个不存在的路径并确认
- **THEN** 显示该路径不存在的错误，不启动、不创建目录
