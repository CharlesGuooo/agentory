# Agent 版本检测（显示，不代劳）

> **2026-08-19：「不代劳」这一条已作废**，Agentory 现在可以一键更新 agent
> —— 但只在用户看得见的终端面板里跑，且只信重读出来的版本号。
> 原因与流程记在 `DESIGN.md` D-22 三。下面保持提案原样，不改写当时的决策。

## 为什么

用户装了哪几个 agent、装的是什么版本、有没有新版 —— 这些今天在 agentory 里**一个都看不到**。
现有的 `availableAgents(resolveCommand)` 只回答「装没装」，返回一个 `AgentId[]`，
连装在哪都丢掉了，而且只在点「新建会话」时才跑。

`docs/research-notes.md:199` 有一条**从没被回收的待办**：

> Grok Build 还在 beta(v0.2.x)，CLI 会变。适配器需要版本探测 + 测试，否则它一改 flag 就静默坏掉。

`DESIGN.md §0` 那张修正表逐条回应了 research-notes 的 §2 / §4.4 / §4.5 / §6-1 / §6-2 / §9，
**唯独跳过了 §6-4**。目前对「agent CLI 会变」的全部应对是 `resume.ts` 那张命令表集中
+ 真机测试兜底（`add-session-resume/design.md:61-65`）。

## 这一刀做哪一半

那条待办其实是两件事：

| | 这一刀 |
|---|---|
| **告诉用户**装了什么版本、有没有新的 | **做** |
| 检测到版本不兼容后**自动适配** resume 参数等 | **不做**（继续靠命令表集中 + 真机测试） |

## 改什么

- 读本机已装版本（**纯文件读，一个 agent 进程都不起**）
- 查最新版（出网，但**只发包名**）
- 设置里新增「Agent」区块；有新版时齿轮上一个小圆点
- 更新命令**只给复制，绝不代跑**

## 不改什么

- **不代跑更新** —— 这个项目已经亲手弄坏过一次 codex
- **不起任何 agent 子进程**，连 `--version` 都不跑
- **不抓不解析 changelog** —— 5 个格式各异、内容无法校验，它们改版式我们就静默坏掉
- **不写死任何链接 URL**

## 一个必须一起改掉的代价

`README.md` 原来写着一句**绝对承诺**：

> turning it on is the only thing in agentory that sends anything off your machine

用户拍板版本检查**默认开**，这句话就变成了假话。所以本变更同时：

- 改写 README 那句：摘要是唯一会把**你的内容**发出去的功能；版本检查出网但只发包名
- 给 D-8 那张表**加第三档**，并修正它的判据（见 design.md）
