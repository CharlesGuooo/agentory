## Why

**用户的第一痛点到现在一点都没解。** 关掉 agentory，所有会话照样消失 ——
和关掉一堆 PowerShell 窗口没有区别。

`DESIGN.md` §1 把「重启恢复」排在三根支柱之首，`README.md` §1 记的用户原话是
「电脑重启后所有窗口消失，而且记不清上次开着哪些会话」。

前置条件已经齐了：索引能列出 437 个会话、`resumeCommand` 五套命令都验过、
多终端与标签页也在了。缺的只是**把「我在用哪些会话」这件事记下来**，以及重启后把它们放回去。

## What Changes

- **工作集**（D-5）：一个用户策展的会话集合，成员资格**只由显式动作改变** ——
  新建会话或从历史恢复即加入，「结束会话」即移出
- **持久化**（D-6）：`workspace.json`，重启后工作集完好无损
- **重启后的状态**：工作集成员全部处于「已停」，侧栏照常列出它们
- **勾选式恢复**（D-12）：顶部横幅列出上次在跑的会话，用户勾选后**串行、后台**恢复，带实时进度

### 本次一并回答两个悬着的问题

**`DESIGN.md` Q7 —— 「结束会话」杀不杀进程？**
**杀。** 它的名字就是「结束」；只移出不结束会留下一个界面上看不见、却还在烧资源的孤儿进程。
「移出工作集但保持运行」这个需求目前不存在，不做。

**D-12 的字面做法不可行，本次按其精神实现。**
D-12 写的是「建好 tab、把 `claude --resume <id>` 打进终端，但不回车」——
要做到这个得先起一个 shell 再往里打字，那个 tab 托管的就变成了 shell 而不是 agent，
pid、退出码、状态追踪全都对不上。
**改为**：tab 以**未启动**状态存在，显示它将要执行的完整命令，点一下才真正起。
达到的效果一样（不自动烧 token、多一次确认），但不引入一个假的 shell 层。

## Capabilities

### New Capabilities
- `workspace`: 工作集的成员资格、持久化、以及重启后的批量恢复

### Modified Capabilities
- `app-shell`: 侧栏改为展示工作集（而非仅当前进程）；新增重启恢复横幅与「结束会话」入口
