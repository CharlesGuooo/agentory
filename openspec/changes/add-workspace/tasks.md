## 7. 本轮抓到的 bug（5.4 的产物）

- [x] 7.1 **✕ 结束会话完全没生效，且一声不响**：27 个进程一个没死，成员数没变，文件没改。
      根因是工作集主键用 `U+0000` 当分隔符，而 **HTML 属性解析会把它改写成 `U+FFFD`**
      （Electron 43 实测：写进去 charCode 0，读回来 65533）。
      于是每一次按 key 的查找都失配 —— **✕ 结束、点未启动的成员启动、切标签页、
      恢复面板单行勾选，四个交互全是哑的**
- [x] 7.2 先写失败测试（主键不含控制字符）再改分隔符为 `|`，红→绿
- [x] 7.3 同类坑的第二个入口：Windows 路径里 `&` 合法，`data-key` 不转义同样会失配。
      所有插进 HTML 的用户字符串统一走 `esc()`，**属性值也转**
- [x] 7.4 补冒烟守门：`START_MEMBER`（点未启动的成员启动 —— 同样走 `data-key`，此前从没验过）
