- [x] 8.1 **注入白名单不成立**。`§2.6` 那张表是白名单，实测连着撞见三个表上没有的包装：

      改成结构规则「以 XML 开标签起头的一律当注入」，并加断言「预览不以 `<` 开头」——
      **codex 那条就是被这条泛化断言抓出来的**，不是我预先想到的
- [x] 8.2 **我自己引入了一处可达性倒退**：把历史行从 `<button>` 改成 `div + role="button"`，
      键盘就激活不了。改成两个并列的真 `<button>`（星标一个、点开一个）——
      比自己补 keydown 干净，也不会补漏一半
- [x] 8.3 **一条我编造的测试用例**（11 字的「把这份简历改成投行版本」）差点让我去改阈值。
      真实数据里的短消息**全部**是没信息的，所以错的是我的用例不是规则。已改用例并把取舍写进注释
- [x] 8.4 **`readHead` 只有行数上限是不够的**：pi 的头部有把整个 README 塞进去的 toolResult 行，
      40 行几 MB，取一条预览 18.8 ms。加 256 KB 字节上限后 pi 226→7 ms、claude 232→59 ms
