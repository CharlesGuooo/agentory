## ADDED Requirements

### Requirement: 通过界面选择主题与明暗

系统 SHALL 提供界面上的主题与明暗选择入口，而不是只能靠快捷键或环境变量。
原规格定义了主题的加载、解析与应用，但未规定用户**如何**选择 —— 本条补上这一半。

#### Scenario: 界面上可选主题

- **WHEN** 用户打开设置
- **THEN** 所有已加载的主题（内置 + 用户）以卡片列出，当前选中的那张有明确标记

#### Scenario: 界面上可选明暗

- **WHEN** 用户打开设置
- **THEN** 明暗以「跟随系统 / 浅色 / 深色」三选一的分段控件呈现
- **AND** 它与主题选择相互独立，切换明暗不改变已选主题

#### Scenario: 选择被持久化

- **WHEN** 用户在界面上选择了主题或明暗，随后重启应用
- **THEN** 重启后仍是所选的组合
